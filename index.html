Certificates that prove themselves.

The SHA-256 fingerprint of each university certificate is stored on the blockchain. Anyone can check a PDF against it. If even one byte changes, the tampering is caught.

University / Student login
Original PDF
9f2b61c4a07d...e18a
Same PDF, one word edited
41ac07e93b5f...02d7

A completely different hash. This is how tampering is detected.

How it works

1
University issues

The admin uploads the PDF and the system generates its SHA-256 hash.

2
Hash goes on blockchain

Only the ID, hash, student ID, issuer address and timestamp are stored. Not the PDF.

3
Student shares

The student downloads the PDF and shares the QR code or certificate ID.

4
Recruiter verifies

Matching hash means VERIFIED. A different hash means TAMPERED.
